# RPK Studio

浏览器里解析、修改并重新签名 Vela 平台的 RPK 分发包。全部计算在本机完成，文件不上传。

在线版：**https://hrk666666.github.io/rpk-studio/**
作者：**hrk_**

## 结构

五个主页面，桌面左侧导航，手机底部导航，可左右滑动切换：

| 页面 | 内容 |
|---|---|
| 包 | 载入、包信息、签名校验、JSC 内嵌版本提示 |
| 编辑 | 应用信息、图标、图片 / 文件资源、签名与导出 |
| 工具箱 | 系统应用伪装 |
| 历史 | 载入与导出记录，保存文件本体 |
| 设置 | 外观、历史与存储、更新、条款、关于 |

签名区块默认收起，点标题展开；直接点导出而身份未设置时会自动展开。

## 编辑

- 改应用名、包名、版本名、版本号
- 换图标：可调整尺寸、拖拽裁剪、圆形裁剪、保持透明
- 图片资源：包内全部图片以缩略图列出，逐张替换或还原；文件列表可单独取出、替换
- 签名：自动生成（随机 CN）或手动填写 C / O / OU / CN 与有效期；也可导入已有密钥
- 导出：重算 `META-INF/CERT` → 重打包 → 重建 `RPK Sig Block 42`，可选用自检

未改动的条目复用原始压缩数据，导出只比原包多出改动部分的差值。

## 签名

**生成**：RSA-2048 + SHA-256，自签 X.509。自动模式下 CN 随机；手动模式可填国家、组织、部门、有效期。

**导入**：可同时选择多个文件，按内容识别类型。

| 类型 | 格式 |
|---|---|
| 私钥 | PKCS#8 PEM、PKCS#1（`BEGIN RSA PRIVATE KEY`）PEM、PKCS#8 DER |
| 证书 | X.509 PEM / DER，会与私钥做一次签名自检确认配对 |
| 公钥 | SubjectPublicKeyInfo PEM / DER，仅用于配对校验 |

`.p12` / `.pfx` 未实现（浏览器里做 PKCS#12 需要 RC2/3DES，代价过高），可用
`openssl pkcs12 -in key.p12 -nodes -out key.pem` 转换后再导入。

**导出**：私钥 PEM、证书 PEM、公钥 PEM，或打包成一个 zip（含说明）。

身份默认自动保存在本机，重启后仍在，可在设置里关闭或删除。

## 工具箱

**系统应用伪装**：按澎湃 OS 4（38 个）与澎湃 OS 3（37 个）分组列出系统应用图标，选中后把
图标换成该应用的图标、应用名改成对应名称；**包名、版本号、其余资源都不动**。

图标来自固件包内的 `launcher.bin`（12 字节头 + 256 色调色板 + 8 位索引），解码后按目标图标尺寸等比放置。

## 历史

每条记录保存时间、包名、名称、版本、体积；开启「保存文件本体」时连同整包一起存在 IndexedDB。
点击记录可以：

- **继续编辑**：把存档重新载入
- **另存为**：导出到本地
- **删除记录**

默认不限条数。设置里有「历史与存储」二级页面：记录开关、保存文件开关、自动保存身份开关、占用统计、清空入口。

## 更新

设置里可关闭自动检测。启动后静默请求仓库中的 `version.json`，只有版本号更高才提示，并展示更新说明。
GitHub 直连不畅时可在设置里填镜像前缀（如 `https://gh-proxy.com`），程序会把它拼在原始地址前。

当前版本的开关只影响检查行为，不会自动下载安装。

## 开发

```bash
npm i
npm run build     # esbuild 打包并同步 HTML 的版本号
```

```
index.html            页面
assets/app.js         界面与流程
assets/md3.css        M3 tokens 与组件
assets/rpk.js         签名块解析 / 生成、X.509、重打包
assets/zip.js         ZIP 读写
assets/icons/         工具箱图标（os3 / os4）与 catalog.json
assets/bundle.js      构建产物
vendor/fflate.js      DEFLATE
version.json          更新清单
android/              Tauri 2 外壳（系统 WebView）
```

## 已知边界

- JSC 包里 `app.jsc` 另存了一份编译时的 manifest，改包名 / 版本只改外层 JSON 时，应用内读到的仍是旧值。界面会提示，但不改字节码。
- 只处理 ZIP 与签名结构，不修改 dex / so 之类的内容。
- 需要 `crypto.subtle` 与 IndexedDB，浏览器要求较新。
